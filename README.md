# Netwoven Claude plugin marketplace

Generated by `tools/mirror_marketplace.py` in the netwoven-weave repository on
Azure DevOps; do not edit here. Every change arrives as a pull request from
the release pipeline; merging it publishes version 2.0.1 of `weave` to
Netwoven's organization marketplace.

Install in Claude Code: `claude plugin marketplace add <this repository>` then
`claude plugin install weave@netwoven`. In Claude Cowork and Chat the plugin
arrives through Organization settings > Plugins.
