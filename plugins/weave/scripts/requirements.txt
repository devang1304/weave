# scripts import. `doctor.py` (stdlib only) reads this file when run with
# `--install`: it creates a venv under ${CLAUDE_PLUGIN_DATA}/venv (default

# interpreter already satisfies the required set, doctor skips the venv and
# points env.json at that interpreter instead.
