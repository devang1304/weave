# Recipe: adoption-comms

Adoption communications plan on the document template: who needs to hear
what, through which channel, and when. This is one of three independent
adoption recipes (`adoption-strategy`, `adoption-comms`,
`adoption-training`) -- pick the one the request actually needs, not all
three at once.

## What each section says

- **Audience**: segments who needs to hear about this and why they're a
  distinct segment -- executive sponsors, people managers, end users, IT
  and helpdesk. Each segment gets a line on what they specifically care
  about, not one paragraph that lumps everyone together.
- **Key Messages**: short and audience-specific. An exec sponsor hears
  about business outcomes and risk; an end user hears about what changes
  in their day-to-day. Never one generic message ("we're excited to roll
  out X") repeated for every audience -- that's a sign the messages weren't
  actually tailored.
- **Channels and Cadence** (`comms-table`): one row per planned
  communication -- audience, message, channel, date. This is the section
  the reader actually uses to execute the plan, so every row needs all four
  cells filled in as far as the source allows. A date the source doesn't
  give is `[TO BE PROVIDED]`, never a guessed date. Same for channel: don't
  assume "email" if the source doesn't say so.
- **Timeline** (optional): the overall communications arc in a few
  sentences (e.g. "teaser two weeks out, launch announcement day one,
  reinforcement messages through week four") -- narrative, not a repeat of
  the table.

## Asking for what's missing

Only `initiative` is required and usually isn't inferable from a generic
source -- ask what's being communicated about in one question if the
source doesn't make it obvious.

## Hard rules specific to this recipe

- Never invent a communication date or a channel the source doesn't
  specify. A gap in the comms table is `[TO BE PROVIDED]`, flagged in chat,
  not a plausible-sounding fill-in.
- Audience and Key Messages must stay distinct: segments go in Audience,
  what's said to each goes in Key Messages. Don't collapse them into one
  section.
