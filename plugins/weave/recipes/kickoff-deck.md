# Recipe: kickoff-deck

Kickoff deck: introduces the project team to itself and to the client
sponsor. Pairs with the `project-charter` recipe (`companion.share`: client,
date, project_name). Build the charter first when both are wanted, and reuse
its answers here rather than asking twice.

## Slide pattern

1. **Cover** (built automatically from `meta`).
2. **Objectives slide** (block/section id `objectives`, required): states
   what success looks like in plain language -- the outcome the client will
   recognize as "done," not a restatement of the SOW's scope language.
3. **Team slide** (block/section id `team`, required): names the Netwoven
   and client roles and people. Never invent a name the source doesn't give
   -- use a role placeholder such as "[Netwoven PM -- TBD]" instead of
   guessing who fills a seat.
4. **Timeline slide** (block/section id `timeline`, required): major
   milestones only, not a detailed task list. If the source gives a full
   plan, distill it to the handful of dates a kickoff audience needs.
5. **Next Steps slide** (block/section id `next-steps`, required): the
   concrete first actions with an owner per line. Never a "Questions?"
   slide.
6. Closers (Confidentiality, Thank You, Closing) are added automatically.

## Hard rules specific to this recipe

- Every name, date, and milestone on this deck must trace to the same
  answer given for the paired project charter, if one was built in the same
  turn. Never let the deck read differently than the charter.
- A missing team member or milestone is a gap for the flag list, not a
  reason to invent a plausible-sounding name or date.
