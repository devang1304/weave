# Recipe: proposal

Pre-sales proposal on the document template, built from scoping notes, a
discovery call, an RFP, or an informal client conversation. This is not a
signed commitment: the `sow` skill is what the client actually signs, and
nothing in this document should read as binding legal or commercial
language.

## What each section says

- **Executive Summary**: the governing thought is the recommended offering
  and the headline value it delivers, first sentence. Do not open with a
  recap of engagement history or a generic capability statement.
- **Understanding Your Needs**: restate the client's problem in their own
  language, drawn from the source material, never a generic description of
  the Microsoft offering. This section is the proof that Netwoven listened;
  a paragraph that could apply to any client is a rewrite, not a pass.
- **Proposed Approach**: the solution and its phases, described at a level
  a non-technical executive reader can follow. Name the phases and their
  sequence; save implementation detail for the SOW that follows.
- **Why Netwoven** (optional — drop the section entirely if the source has
  nothing differentiated to say rather than filling it with boilerplate):
  a section built from "proven methodology" or "trusted partner" filler is
  worse than no section at all.
- **Investment Summary** (`investment-table`): state plainly, in the
  section's opening sentence, that these are rough order of magnitude
  figures, not final pricing, and that a signed SOW will confirm the fee.
  Use ranges, not false-precision numbers, and only where the source
  supports a range.
- **Next Steps**: the concrete actions that move the client toward a
  signed SOW (a scoping call, a decision date, a pilot).

## Asking for what's missing

Only `offering` is required and usually cannot be inferred reliably from
loose source material — ask for it in one question if the source doesn't
already name the Microsoft offering or solution clearly. Never ask for
anything else this recipe doesn't list as `required`; a missing optional
section (Why Netwoven) is a gap to drop, not a question to ask.

## Hard rules specific to this recipe

- Never state or imply a signed commitment: "agreed scope", "effective
  date", "the parties agree", or similar language belongs to the `sow`
  skill only, never to a proposal.
- A missing investment figure is `[TO BE PROVIDED]`, never a fabricated
  number, range, or "typical" figure the source doesn't support.
- The Investment Summary is always rough order of magnitude. Even when the
  source gives a precise number, present it as an estimate range unless the
  source itself calls it final pricing.
